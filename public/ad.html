STEP 1 · R2 & FIREBASE RULES

নতুন Cloudflare R2 Storage Server যুক্ত করার সহজ বাংলা টিউটোরিয়াল ও Firebase Rules

একটি সার্ভারের 10GB ফুল হয়ে গেলে নিচের নিয়ম মেনে খুব সহজেই নতুন Cloudflare R2 Storage Server যুক্ত করতে পারবেন

ধাপে ধাপে নতুন Cloudflare R2 Storage তৈরির নিয়ম:

  1. প্রথমে আপনার Cloudflare Dashboard-এ লগইন করে বাম পাশের মেনু থেকে R2 Object Storage-এ যান এবং Create Bucket বাটনে ক্লিক করে নতুন একটি Bucket খুলুন (যেমন: bd-videos-2)।
  2. এবার আপনার তৈরি করা Bucket-এর ভেতরে গিয়ে Settings ট্যাবে যান। নিচে Public Access (R2.dev subdomain) অপশন থেকে Allow Access অন করুন এবং সেখান থেকে আপনার Public Bucket URL কপি করে রাখুন (যেমন: https://pub-xxxx.r2.dev)।
  3. এরপর বাম পাশের মেনু থেকে Workers & Pages → Create → Create Worker-এ ক্লিক করুন। যেকোনো নাম দিয়ে Deploy করুন। তারপর Edit Code বাটনে ক্লিক করে নিচের বক্সের Cloudflare Worker Code-টি কপি করে সেখানে সম্পূর্ণ পেস্ট করে উপরে ডান পাশে Deploy বাটনে ক্লিক করুন।
  4. এখন Worker-এর Settings → Bindings → Add → R2 Bucket সিলেক্ট করুন:
    • Variable name বক্সে বড় হাতের অক্ষরে লিখুন: BUCKET
    • R2 bucket অপশনে আপনার নতুন Bucket-টি সিলেক্ট করে Deploy দিন।
  5. এরপর একই জায়গায় Variables and Secrets → Add বাটনে ক্লিক করুন:
    • Variable name বক্সে লিখুন: ADMIN_KEY
    • Value বক্সে আপনার নিজের পছন্দমতো একটি গোপন পাসওয়ার্ড দিন (যেমন: mysecret123) এবং Deploy দিন।
  6. সবশেষে Upload & Storage ট্যাবে গিয়ে + Add Storage Server বাটনে ক্লিক করে আপনার Server Name, Worker API URL, Public R2 Stream URL, এবং আপনার দেওয়া ADMIN_KEY বসিয়ে Save করুন!
১. Cloudflare Worker Code (CORS Fixed + Upload/List/Delete)
